# Obsidian Index

The `obsidian/` folder is a self-contained mini-vault for this project. To use it:

1. Open Obsidian.
2. Open the existing vault at `/Users/parthsingh/AI-Brain/Obsidian-Vault` (which is the project root for this run).
3. The notes appear under the `secret-knock-lock-simulation/obsidian/` subfolder. All `[[wikilinks]]` between them resolve automatically.
4. The main entry point is `[[Secret Knock Lock Simulation]]`.
