### Microphone Input Engineer

- New file `src/simulation/MicKnockDetector.tsx`.
- Uses `navigator.mediaDevices.getUserMedia({ audio: { echoCancellation: false, noiseSuppression: false, autoGainControl: false } })` to avoid browsers eating quiet knocks.
- AudioContext + AnalyserNode (fftSize 1024) feeding RMS calculation each animation frame.
- Slow EMA baseline (time constant 0.985, floored at 0.003) tracks room noise. Baseline is NOT updated during spike frames so a single loud knock can't pollute it.
- Detection rule: `rms > sensitivityThreshold AND rms > baseline*4.0 AND now - lastTrigger > 1500ms`.
- UI panel includes: status (8 states), live audio meter with threshold marker, sensitivity slider, enable/disable button, contextual help text.
- On detection, fires `play_unlock` on the existing `cmdRef` — no changes to `AnimationController` were needed.
